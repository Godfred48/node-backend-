CLAUDE:
You're close, Godfred. <% ... %> runs JavaScript logic, like your forEach loop, but it doesn't put anything on the page by itself. <%= ... %> takes a value, such as project.title, and outputs it into the page as text, with special characters like < and > converted to harmless versions. That conversion is the escaping you mentioned. It doesn't display HTML. It treats whatever the value contains as plain text.

There is also a third tag in your file: <%- include('partials/header') %>. The - outputs content without escaping it. Why do you think the header include needs the unescaped tag, while project.title uses the escaped one?

CLAUDE:
Exactly right, Godfred. The header is code you wrote yourself, so it's safe to output unescaped, and project.title comes from the database, where it could contain something harmful.
