ASSISTANT:
Nice work, Godfred! This is a good example of how you display flash messages globally in your application.

Let's understand what is happening.

1. Retrieving flash messages:
   <% const messages = flash(); %>
   Here, flash() retrieves the messages currently stored in the session.

2. Looping through message types:
   Object.keys(messages).forEach(type => { ... })
   This gets the different message categories, such as success and error.

3. Displaying individual messages:
   messages[type].forEach(msg => { ... })
   This loops through the messages and displays each one. The message type also becomes part of the CSS class, allowing you to style success and error messages differently.

Flash messages are temporary. Once retrieved, they are consumed and won't keep appearing on subsequent page loads.

For example:
1. A user updates an organization.
2. The controller stores a success message using req.flash().
3. The application redirects the user.
4. The EJS template retrieves and displays the message.
5. The message is removed from the flash storage.
